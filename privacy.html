The Sea Level Zero tool is a private tool that posts Sea Level Zero's own videos to Sea Level Zero's own accounts. It is not offered to the public.

What it accesses

When the account owner signs in with Google, the tool receives an access token for the Sea Level Zero YouTube channel. It uses it only to upload the channel's videos, set the channel's description and banner, and read the channel's own video statistics and public comments (to pick the next city requested by viewers).

What it stores

The token is stored on one private server, readable only by the owner. Video statistics and public comment text are stored there to build the channel's own reports. Nothing is sold, shared or used for advertising.

Google user data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services: see the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions; stored data is deleted on request.
